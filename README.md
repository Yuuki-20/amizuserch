# 「あみ図がなくて困っている」市場の調査

調査日：2026-10-31　対象：日本国内のかぎ針編み・棒針編みをする人（海外の参考データも含む）

> **データの確かさについて**
> この調査をした環境からは、官公庁サイト（stat.go.jp、e-stat.go.jp など）を直接開けなかった。
> 数値は検索エンジンが返した原典の抜粋で確かめたもので、各行に「確認度」を付けた。
> 資料に載せる前に、[9. 原典で照合する表](#9-原典で照合する表) の表を e-Stat で開いて確かめること。

## 1. 結論

1. **土台になる人数は公的統計で示せる。** 総務省「社会生活基本調査」では、過去1年に「編み物・手芸」をした人（10歳以上）は **2021年に991万人（8.8%）**。2006年からは約1,000万〜1,200万人の範囲で推移している。
2. **2021年の値はブームの前のもの。** 編み物ブームは2023年秋〜2024年秋に始まった。業界の数字では、新宿オカダヤ本店の毛糸売上は **2年で約6倍**、ユザワヤの毛糸関連は **+50%**。増えたのは **10〜20代の、かぎ針で小物から始める初心者**。今の実数は2021年の値より多いと考えられる。公的統計で確かめられるのは、2026年10月に行った令和8年調査の結果が出る2027年。
3. **「あみ図がない」は構造的に起きる。**
   - 国内では記号で書くあみ図が標準になっている（JIS L 0200／L 0201 の編目記号）。一方、海外のパターンの多くは英文で、Ravelry だけでも約120万件ある。記号図に慣れた人には読みにくい。
   - 新しく始める人は SNS の完成写真を見て作りたくなるが、作者があみ図を公開も販売もしていないことが多い。
4. **技術的にもまだ解けていない。** 2025年の学術ベンチマーク CrochetBench では、GPT-4o・Claude・Gemini などの画像も扱えるAIは、写真から「そのまま編める」手順を出すのが最も苦手だった。写真や英文からあみ図を起こし、目数のつじつままで確かめる仕組み（amizuAI のやり方）には、まだ先行者がいない余地がある。
5. **足りない証拠：** 「あみ図がなくて困っている人が何人いるか」を直接数えた公的データは無い。困りごとの割合は、自分たちのアンケートで測る必要がある（[8章](#8-次にやること)）。

## 2. 「あみ図がなくて困る」場面の型

| 型 | 場面 | 裏付け |
|---|---|---|
| A. 写真しかない | SNS で見た作品、店の既製品、家族の古い手編み | ブームは SNS が起点（4章）。作品を売る店でも「編み図の配布・販売はしていない」と明記する例がある[^gosyo] |
| B. 英文しかない | Ravelry や海外の作家のパターン | 国内は記号図が主流で、海外は英文が主流。高校生の研究発表もこの問題を出発点にしている[^ieice] |
| C. 文章だけで図がない | 書籍や作家のブログの文章による説明 | 記号図は全体の形をつかみやすく、文章は順番をつかみやすい。読みやすさが人によって違う[^ronique] |
| D. 自分のアイデアを図にしたい | 作品の販売や、教えるための清書 | 編み図の販売を副業にする解説記事が増えている[^atsoho] |

amizuAI はこのうち **A（写真）・B（英文）・C（文章）** を入力として受け付ける。

## 3. 市場の土台（公的統計）

### 3.1 「編み物・手芸」をした人の数（総務省 社会生活基本調査）

| 調査年 | 行動者数 | 行動者率 | 確認度 |
|---|---|---|---|
| 2006（平成18年） | 1,239万人 | – | 二次資料[^jbpress] |
| 2011（平成23年） | 1,157万人 | – | 二次資料[^jbpress] |
| 2016（平成28年） | 1,198万人 | **10.6%** | 率は統計局の結果概要に載っている[^stat2021en] |
| 2021（令和3年） | **991万人** | **8.8%** | 率は統計局の結果概要と茨城県の報告書に載っている[^stat2021en][^ibaraki] |

- 行動者率は、10歳以上の人のうち、過去1年間にその活動をした人の割合。2021年調査は約17万人（171,360人）に聞いた国の基幹統計[^statista]。
- 「編み物・手芸」には刺しゅうなども含まれる。**かぎ針・棒針だけの人数は公表されていない。**
- 2021年は新型コロナの影響下で、ブームの前。2016→2021年の −1.8ポイントは、ブーム前の長い減少傾向を表している（京都府の統計解説も「緩やかな減少傾向」としている[^kyoto]）。

### 3.2 都道府県別（2021年）

- 1位 北海道 10.7%、2位 岩手県 10.5%、3位 神奈川県 9.7%。最下位は沖縄県 6.7%[^stats47]。
- 京都府は 9.3% で、2006年以降ずっと全国を上回っている[^kyoto]。
- 寒い地域や首都圏で多い。地域を絞った広告や、手芸店と組む先を選ぶときの手がかりになる。

### 3.3 次の公的データ

- **令和8年社会生活基本調査は2026年10月に実施された**[^stat2026]。結果は2027年に公表される予定で、ブームで人数がどれだけ増えたかを公的統計で示せるようになる。公表されたら、この表を更新する。

## 5. 「あみ図がない」が構造的に起きる根拠

### 5.1 国内は記号図、海外は英文

- 日本には、編目記号の JIS 規格がある（**JIS L 0200「編目の表し方」1976年、JIS L 0201「編目記号」1995年**）[^jis]。国内の本や雑誌はこの記号図で書かれている。
- 世界最大の編み物サイト Ravelry は、登録ユーザー約900万人・月間アクティブ約100万人（2020年）[^wiki]。パターンは **約120万件**（2022年）[^ravelry]。多くは英語の文章（略語）で書かれている。
- 国内で記号図に慣れた人にとって、この大量の英文パターンは使いにくい。東京都立多摩科学技術高校の研究発表（電子情報通信学会 ISS ポスター）も、これを課題として英文から編み図を作るプログラムを試している[^ieice]。

### 5.2 写真しか公開されない

- ブームのきっかけは SNS（LE SSERAFIM の SAKURA さんの投稿など）[^jprime]。目に入るのは完成した作品の写真で、あみ図は付いていないことが多い。
- 作品を売る店でも、あみ図は配らない・売らないと明記する例がある[^gosyo]。作者にとってあみ図は売り物なので、公開されないこと自体は当然。

### 5.3 技術はまだ追いついていない（学術研究）

| 研究 | 内容 | 示すこと |
|---|---|---|
| **CrochetBench**（arXiv 2511.09483、2025年。ACL 2026 にも掲載）[^crochetbench] | 6,085件のかぎ針パターンで、9種類の画像も扱えるAI（GPT-4o、Claude Sonnet 4、Gemini 2.5 など）を評価 | **写真から「そのまま編める」手順を出すのが最も苦手。** 大きいモデルほど存在しない編み目を作ってしまう。追加学習しても、手順として正しいかどうかは良くならない |
| 英文パターンを CrochetPARADE の書式に直す研究（AAAI 2025 シンポジウム）[^aaai] | LLM を追加学習して変換 | 最良でも正解率 74% |
| 写真からあみぐるみのパターンを作る研究（ライデン大学 修士論文 2025）[^leiden] | GPT-4o と o1 で生成 | もっともらしいものは作れるが、検証は限られている |
| Neural Inverse Knitting（MIT、ICML 2019）[^nik] | 編み地の写真から機械編みの命令を作る | 機械編みの平らな編み地だけが対象 |

→ **AI に生成させるだけでは編めるあみ図にならない。** amizuAI は中間データを1目ずつ展開して目数の整合を確かめ、エラーを AI に戻して直させる。CrochetBench が示した弱点（編めない手順を出す）をそのまま補うやり方で、これが差別化の根拠になる。

## 6. 市場規模の試算（仮置き）

| 段階 | 定義 | 規模 | 根拠 |
|---|---|---|---|
| TAM | 過去1年に編み物・手芸をした人 | **約991万人**（2021年。ブーム後は増えている見込み） | 社会生活基本調査 |
| SAM | そのうち、かぎ針・棒針で編む人 | **約300万〜500万人**（仮定：30〜50%） | 内訳の公表値は無い。**アンケートで確かめる** |
| 困っている人 | そのうち、この1年に「あみ図が無くて作れなかった／諦めた」経験がある人 | 未測定 | **アンケートで確かめる** |
| 初年度の目標 | 招待制で試してもらう人 | 数百〜数千人 | 運営の都合で決める |

- 300万〜500万人は、刺しゅう・パッチワークなど他の手芸との割合を仮に置いた幅で、**根拠のある値ではない**。資料では「仮定」と明記すること。
- 公的統計で確かな数字を言えるのは TAM まで。そこから先は自分たちのアンケートで裏付ける。

## 7. 法的な注意点（プロダクト設計への示唆）

- 編み図や作品写真は、表現に創作性があれば著作物になり得る。一方、一般的な編み方や目数といった技法・アイデアそのものは保護されないと一般に解されている。**編み図に絞った判例は、今回の調査では見つからなかった。**
- 著作権法30条の私的使用のための複製は、自分で編むための個人利用が前提。**作ったあみ図の販売・配布には使えない。**
- 設計への示唆：
  - 利用規約と画面で「他人の作品から起こしたあみ図は個人で使う範囲に限る」と伝える
  - 共有や販売の機能を作るなら、自分の作品であることを確認する手順を入れる
  - 具体的な運用は弁護士に確認する

## 8. 次にやること

1. **原典で数値を照合する**（[9章](#9-原典で照合する表)）。
2. **アンケートで「困っている度合い」を測る**（招待制の利用者と、手芸店や編み物カフェの協力者が対象）：
   - この1年に、あみ図が無くて作るのを諦めた作品はあるか（回数）
   - そのときに手元にあったものは何か（写真／英文／文章／実物）
   - 記号図と英文のどちらが読めるか
   - あみ図が手に入るなら、1枚いくら払うか
3. **令和8年社会生活基本調査の結果（2027年公表予定）が出たら、3.1の表を更新する。**
4. 補助の指標として、Google トレンドの「編み図」「かぎ針 編み図 無料」の推移や、SNS の作品投稿に付く「編み図ありますか」といったコメントの件数を集める。
